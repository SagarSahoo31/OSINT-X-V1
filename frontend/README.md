# OSINT-X Frontend (Next.js 14 + Tailwind CSS + shadcn/ui)

Professional SOC & Threat Intelligence Dashboard for OSINT-X.

## Key Views
- **Dashboard**: High-level exposure metrics, recent investigations, risk distribution.
- **Investigations**: Investigation lifecycle management, launch wizard, target validation.
- **Findings & Evidence**: Filterable findings explorer with source provenance and confidence ratings.
- **Relationship Graph**: Interactive node-link topology powered by React Flow.
- **Timeline**: Chronological discovery view comparing asset states across investigations.
- **Reporting**: Report generation and export center (PDF, JSON, CSV).
- **Settings**: System configurations, API keys, collector tuning, and user management.
