# Containerized Collectors Sandbox

This directory contains standalone Dockerfiles and configs for external OSINT tools that require isolated environments, distinct system packages, or non-Python dependencies:

- `holehe/`: Holehe email account discovery sandbox
- `maigret/`: Maigret username footprint discovery sandbox
- `amass/`: OWASP Amass attack-surface discovery sandbox
- `infrastructure/`: DNS, HTTPX, WhatWeb, and Certificate tools sandbox
